# StarStruck Beauty Experience

An independent, interactive beauty-commerce concept demonstration by JARVIS Agency. This is not an official StarStruck website and is not affiliated with or endorsed by StarStruck or Sunny Leone.

## Features

- Editorial homepage and responsive navigation
- Local catalog with clearly labeled demonstration products and illustrative NPR pricing
- Beauty Finder with combined search, category, color-family, finish, price, and sort filters
- Shade Explorer with selectable swatches and comparison of up to three shades
- Curated Shop the Look page with product links and add-look-to-bag interaction
- Product detail pages with shade selection, quantity controls, wishlist, and related products
- Wishlist persisted in browser local storage where supported
- Local demonstration shopping bag with quantity changes, remove actions, and subtotal calculation
- Demo campaign page
- Checkout disclaimer: no order or payment is submitted
- Responsive layouts, keyboard focus styling, semantic labels, and reduced-motion support

## Run locally

This is a static website and does not require Node.js, a backend, or API keys.

1. Download or clone this repository.
2. Open `index.html` directly in a browser, or use the VS Code **Live Server** extension.
3. Navigate using the header links.

## GitHub Pages

1. Create a GitHub repository, for example `starstruck-beauty-experience`.
2. Upload `index.html`, `README.md`, `.gitignore`, and `LICENSE` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Demo data and imagery

Product names, descriptions, shade data, and prices are illustrative and should not be treated as verified current StarStruck catalog information. Product and editorial images are remote image URLs used for demonstration and may require internet access. Images are marked as demo imagery in the interface where displayed. Replace assets with approved, licensed brand assets before any public commercial use.

## Important limitations

- No AI services or AI features are used.
- No backend, inventory, account, analytics, or live store integration is included.
- Wishlist and bag are local demo interactions; browser storage may be unavailable in private or restricted sessions.
- Checkout is intentionally nonfunctional beyond showing the demo notice.
- NPR is used as a demonstration currency, not a verified store price currency.
